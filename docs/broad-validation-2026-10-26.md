baseline or candidate skill folders, and permission to work in isolated local
directories. They did not receive the expected answers, source audit findings or
each other's results. The root reviewer inspected resulting artifacts, not merely
self-reported summaries. One execution per version is not a controlled benchmark.

four supplied security snippets without a query-based absence claim; the

They explicitly selected skills; they do not test automatic host activation.

  bottleneck despite aggregate spare capacity, a historical accepted decision
  versus a newer draft/copied evidence, and participant-aware research synthesis.
  Their simple no-op contrasts avoided gratuitous workflows. All passed, so no
  PM runtime expansion was justified. These were not blinded experiments.
- An executed offline Sentry monitor probe emitted `ALL_CHECKS_PASSED` for a
  fixture with a cancelled required package gate; its genuine-all-pass control
  also passed. The useful upstream workflow was adapted without copying that
  helper or weakening this suite's required-check policy.
- A deterministic local Node async-render fixture showed request-shared state
  leaking Bob into Alice's result; applying existing request-local ownership
  preserved overlapping and sequential outputs and immutable shared config.
  This supports the existing guidance in that fixture, not React or production.
- Local repository gate: PM ran 329 unit tests, with 21 platform skips.
  SWE metadata and local-reference validation passed. These static/structural
  checks do not establish model behavior or every runtime integration.
- Required repository validators and remote CI are recorded for the actual PR
  head by their check results. No paid model evaluation, deployment, production
  exploit, external message or upstream tool installation was used.

## Limits retained

and every language/framework rule are not claimed as fully implemented equivalents.
Exact specialist sources remain available in the map for a matching task. No
universal market coverage, perfect activation, release certification, or measured
subscription/token savings follows from these results. Proposed tests in the case
outputs are not represented as executed application tests.
