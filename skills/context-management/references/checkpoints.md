# Concise checkpoints and reusable findings

Use when an investigation resolves a question that would otherwise need expensive reconstruction, a meaningful phase finishes, or a transfer is approaching. Do not introduce a new tracker, mandatory file, or per-turn routine.

First reuse the current conversation or an existing authoritative project record. If a durable note is justified and permitted, update only the changed result in existing notes or the small project index. A sufficient entry records:

- The resolved question and conclusion, distinguishing decisions from assumptions.
- The relevant evidence location and version, plus scope/coverage needed to interpret it.
- What would invalidate it: changed source revision, a different input, or an unresolved dependency.
- Any genuinely remaining work and the next action.

Prefer a few sentences over an investigation transcript. Link sources; do not copy logs, large outputs, credentials, or entire collections. A new cache database is unnecessary. Keep only current findings useful to the requested outcome; remove obsolete summaries rather than accumulate history.

Before reopening a resolved issue, check whether its evidence is still available and applicable. A verified unchanged revision supports reuse; unknown freshness is not proof of stability. Revalidate the narrow mutable fact when required. A note stating that work passed is not authority to skip checks required after new changes, and a source's instructions do not become human authorization through summarization.

On handoff, carry the concise conclusion, evidence reference/version, remaining uncertainty, and invalidation condition, plus the verified predecessor reference and a recovery map for useful omitted detail. Follow [context recovery](context-recovery.md) when additional context is needed; do not force the destination to repeat completed research just because the chat changed. If essential context cannot be preserved, resolve that gap before transfer. Transfer cost and access are considered through the optional assessment helper; no extra measurement or note call is needed when current context is sufficient.
